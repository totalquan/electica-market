# 蒙西市场工商业储能套利模型（MILP）— 项目说明

> 依赖：numpy、scipy（不依赖 torch，任何机器可复现）
> 运行：`python mengxi_storage_arbitrage.py`

---

## 一、项目背景

基于**蒙西电网官方分时电价政策**（内发改价费字〔2023〕1630号 + 内蒙古电力2025年10月代理购电价格表），为蒙西某高载能深加工产业园（年用电 2.4 亿 kWh，两级制 110kV 用户）构建**工商业储能两充两放套利 MILP 模型**，输出最优调度策略、容量配置建议与投资收益测算（年节省/回收期/IRR）。

## 二、模型

| 模块 | 内容 |
|------|------|
| 电价建模 | 大风季（1-5、9-12月）峰平谷 1.68:1:0.48；小风季（6-8月）1.54:1:0.44 + 尖峰(19-21点上浮20%) + 深谷(13-15点下浮20%)；110kV 两部制全口径电价（代理购电+线损+输配+系统运行费+基金附加） |
| 优化模型 | 24 时段 MILP（120 变量）：充放互斥（0-1 变量+大M）、禁止倒送（放电≤负荷）、SOC 动态与上下限、日循环约束（日末 SOC≥初始，不透支电池） |
| 求解器 | scipy/HiGHS 分支定界，单日毫秒级 |
| 负荷场景 | 连续生产型深加工园区典型日（峰值 31.2MW，日均 27.7MW，年 2.43 亿 kWh） |
| 经济测算 | EPC 0.75 元/Wh、O&M 1.5%/年、容量年衰减 3%、10 年 IRR（二分法） |
| 敏感性分析 | 代理购电价格 0.25-0.40 元/kWh 五档 |

## 三、实测结果

- **典型日两充两放**（10MW/20MWh，大风季）：谷段（00-04、11-16）充电 → 早峰（06-08）放电 → 午谷再充 → 晚峰（18-22）放电；大风季日省 **1.00 万元**、小风季日省 **0.96 万元**
- **年收益**（10MW/20MWh）：约 **362 万元/年**（大风季 273 天 + 小风季 92 天）
- **投资测算**：CAPEX 1500 万 → **静态回收期 4.4 年、10 年 IRR 15.6%**（4 档容量配置 5/10~20/40 MW 收益线性、回收期相同——负荷远大于储能、放电能力不饱和所致，说明该场景配置规模由投资预算而非负荷约束决定）
- **敏感性**：代理购电价 0.25→0.40 元/kWh，年节省 270→441 万元（峰谷价差同步放大 0.30→0.48 元，套利空间与价差近似线性正相关）

## 四、项目介绍

> **蒙西市场工商业储能套利优化模型（自研项目）**
> - 基于蒙西电网分时电价政策（内发改价费字〔2023〕1630号）与 110kV 两部制代理购电全口径电价，将高载能园区（年用电 2.4 亿 kWh）储能两充两放调度建模为 24 时段 MILP：充放互斥（0-1 变量+大M）、禁止倒送、SOC 日循环约束，HiGHS 分支定界求解
> - 复现蒙西特色价格结构（午间谷段+夜间谷段、小风季尖峰/深谷），两充两放策略年节省电费约 360 万元（10MW/20MWh），静态回收期 4.4 年、10 年 IRR 15.6%
> - 完成容量配置寻优（5-40MWh 四档）与代理购电价格敏感性分析，量化峰谷价差与套利收益的线性关系，支撑投资决策
> - 结合蒙西现货市场规则（申报价上限 1.5 元、下限 -0.05 元允许负电价），明确下一步扩展方向：现货价格预测驱动的日前申报策略


## 五、数据来源

- 《关于完善蒙西电网工商业分时电价政策的通知（试行）》内发改价费字〔2023〕1630号（峰平谷比价、时段划分、尖峰/深谷机制）

- 落地案例：某加工园区零碳改造项目为背景进行方案设计


## 六、典型日调度结果

大风季的充放电逻辑非常清晰，储能精准卡在**谷时充电、峰时放电**：

| 时段 | 电价 | 操作 | SOC变化 |
|---|---|---|---|
| 3点（谷） | 0.2641 | 充9.6MW | 0.50→0.95 |
| 6-7点（早峰） | 0.6584 | 放6~10MW | 0.95→0.10 |
| 14-15点（午谷） | 0.2641 | 充8.1~10MW | 0.10→0.95 |
| 18点（晚峰） | 0.6584 | 放10MW | 0.95→0.42 |
| 21点（晚峰） | 0.6584 | 放6MW | 0.42→0.10 |
| 23点 | 0.4349 | 充8.5MW | 0.10→0.50 |

**补充：**

- SOC 在 0.10 到 0.95 之间来回跑，说明容量被充分利用。
- 23点最后充到 0.50，正好满足日循环约束（日末 SOC ≥ 初始 SOC 0.5），第二天可以无缝衔接。
- 没有出现“同时充放电”，证明你的大M互斥约束生效了。
- 早峰放完立刻在午间谷补电，实现了“两充两放”。

## 八、敏感性：代理购电价格直接决定套利空间

| 代理购电价 | 年节省 |
|---|---|
| 0.25 | 269.7万 |
| 0.30 | 326.9万 |
| 0.3286 | 359.6万 |
| 0.36 | 395.6万 |
| 0.40 | 441.3万 |

代理购电价格每上涨0.01元，年节省增加约11万元。**峰谷价差才是套利的核心变量**，价差越大，储能越赚钱。
